# 🔍 Palindrome Checker App

A simple and interactive web application that checks whether a word, number, or phrase is a palindrome.

A palindrome is a word, number, or phrase that reads the same forward and backward.

## 🌐 Live Demo

[**Try Palindrome Checker App**](https://tiny-flan-d7a6fd.netlify.app/)

## ✨ Features

- Check whether a word or number is a palindrome.
- Simple and user-friendly interface.
- Instant results.
- Easy-to-use input field.
- Lightweight and responsive design.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 📸 How It Works

1. Enter a word, number, or phrase.
2. Click the Check button.
3. The app checks whether the input reads the same forward and backward.
4. Get your result instantly.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/VaibhavSain/Palindrome-Checker-App.git
```

Navigate to the project directory:

```bash
cd Palindrome-Checker-App
```

Open `index.html` in your browser.
